1. What is Artificial Intelligence (AI)?
AI means making computers do things that normally need human thinking, like learning, making decisions, and solving problems.
 Examples: a chess program, voice assistants like Siri.

2. What is Machine Learning (ML)?
ML is a part of AI. Instead of writing every rule by hand, we give the computer lots of data and it finds patterns by itself.
  Example: a spam filter. It looks at thousands of spam and normal emails and learns the difference.

Types of ML:
- Supervised learning:** the data comes with answers (for example, a photo labeled "cat")
- Unsupervised learning:** no answers are given. The computer finds groups on its own.
- Reinforcement learning:** the computer learns by trial and error and gets rewards for good actions.

3. What is Deep Learning (DL)?
Deep Learning is a type of ML. It uses neural networks with many layers, inspired by the human brain. It needs a lot of data and a powerful computer.
  Examples: face recognition, speech-to-text, chatbots like ChatGPT and Claude.

4. Difference between AI, ML, and DL
AI, ML, and DL are connected, but they are not the same thing. Think of three circles, one inside another:
  Artificial Intelligence (AI) - is the biggest idea. It means making machines act smart, like a human. A chess program that plays against you is AI,
even if it just follows rules written by a programmer.

  Machine Learning (ML) - is a smaller part inside AI. The difference is that ML does not follow rules written by a human. Instead, 
it learns from data. For example, a spam filter looks at thousands of emails and learns by itself which ones are spam.

  Deep Learning (DL) - is an even smaller part inside ML. It uses neural networks with many layers, inspired by the human brain. 
It works best with very large amounts of data and powerful computers. Face recognition and chatbots like ChatGPT and Claude are examples of Deep Learning.

  In short: all Deep Learning is Machine Learning, and all Machine Learning is AI, but not all AI is Machine Learning.

5. Real-world applications of AI

- Healthcare: finding diseases in X - ray images
- Transport: self - driving cars
- Entertainment: Netflix and YouTube recommendations
- Translation: Google Translate
- Banking: detecting fraud
- Education: personal learning assistants
